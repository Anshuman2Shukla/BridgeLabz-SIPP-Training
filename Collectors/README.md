# Java Collectors Practice

This folder contains Java examples for practicing `Collectors` API:

1. Student Result Grouping - groupingBy with mapping
2. Word Frequency Counter - groupingBy with counting
3. Order Revenue Summary - summingDouble
4. Employee Salary Categorization - groupingBy with averagingDouble
5. Library Book Statistics - groupingBy with summarizingInt

Each file has a `main()` method demonstrating the collector usage.
