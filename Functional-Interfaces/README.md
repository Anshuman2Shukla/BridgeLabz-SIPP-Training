# Java Interface Practice – Examples

This pack contains examples of different types of interfaces in Java:

- Defining & Implementing Interfaces
- Functional Interfaces (Predicate, Function, Runnable)
- Static Methods in Interfaces
- Default Methods in Interfaces
- Marker Interfaces (Serializable, Cloneable, custom)

Each file has a `main` method with a short demonstration.

> Compile & run any file individually (no external deps):
```
javac FileName.java && java FileName
```
