# Java Regex Practice – 15 Problems

This pack contains **15 standalone Java programs** demonstrating common regex validations, extractions, and replacements.

Each file has:
- A `regex` (or method) implementing the solution
- A `main` with quick demo tests using the examples from the prompt

> Compile & run any file individually (no external deps):
```
javac Problem01_ValidateUsername.java && java Problem01_ValidateUsername
```
(Replace the filename/class accordingly.)
