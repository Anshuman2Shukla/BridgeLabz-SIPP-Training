# Smart City Transport & Service Management System (Java 8)

This project demonstrates a compact, extensible Java 8 implementation covering:
- Lambda expressions and method references
- Default & static methods in interfaces
- Stream API usage with Collectors: groupingBy, partitioningBy, summarizingDouble
- Functional interfaces (FareCalculator)
- Marker interface (EmergencyService)
- ForEach and real-time style dashboard printing

Run the main demo:
```
javac *.java
java SmartCitySystem
```

Files included:
- TransportService.java
- GeoUtils.java
- FareCalculator.java
- EmergencyService.java
- BusService.java, MetroService.java, TaxiService.java, FerryService.java
- Passenger.java, Trip.java
- SmartCitySystem.java (main demo)
- README.md
